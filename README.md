# Portfolio Websites

A collection of portfolio website templates, where each design is maintained in a separate branch.  
This repository is intended to help beginners and students quickly explore, clone, and customize different portfolio layouts.

---

## 📌 Repository Purpose

This repository is structured as a **multi-branch portfolio template hub**.

- The `main` branch contains documentation only.
- Each **individual branch** contains a complete portfolio website.
- Every branch is independent and can be used as a starter template.

No frameworks are forced. Each project focuses on clarity, structure, and ease of customization.

---

## 🧠 How It Works

- One branch = one portfolio design
- Each branch includes:
  - HTML, CSS, and JavaScript (if needed)
  - Basic project structure
  - Ready-to-use layout

You can switch branches to explore different designs or clone a specific branch directly.

---

## 🌱 Who This Is For

- Beginners building their **first portfolio**
- Students learning frontend development
- Developers looking for **simple portfolio templates**
- Anyone who wants a clean base to customize
